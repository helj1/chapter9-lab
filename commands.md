pwd : Shows the current working directory.

ls : Lists files and folders in the current woring directory.

git init : Initializes a new local git repository.

git status : Shows the current state of the git repository, for instance tracked, staged or modified.

git add : Tells Git to get the changes ready to be saved.

git commit : Saves the changes into the project's history.

git log --oneline : Shows the commit history in order
