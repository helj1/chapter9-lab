## Reflection
Git is helpful for tracking project history.

Git is a great tool for web programming.

1. It keeps the folder clean by tracking every change in one place instead of keeping different versions of the folder.
2. Because it shows us exactly where we are in the process, for example which files are saved or which files are waiting to be saved.
3. The staging area is a place where we organize specific changes before they are saved to the project history.
4. An untracked file is a file that is not part of Git yet, while a modified file is a part of the Git with unsaved changes.
5. It uses this information to record who made each change so everyone can see which person updated the files.
6. git init creates a .git subdirectory that stores all the information needed to track the project's changes.
7. It creates a list of notes that helps the people who are part of the project understand clearly what was changed and why.
8. What I found easiest in this chapter were the basic shell commands like pwd and ls, since I was familiar with it.
9. The hardest part was understanding the staging area and why we need an extra step before saving our work.
10. VS Code makes Git easier to use by showing the changes with colors and providing a simple menu where we can click buttons instead of typing every command.
